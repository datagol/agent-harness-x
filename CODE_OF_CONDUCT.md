# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep disagreements about the work,
and do not harass anyone. Maintainers may remove, edit, or reject comments,
commits, issues, and pull requests that do not follow this, and may block
repeat offenders.

Report unacceptable behavior to the maintainers through a private message on
GitHub to @jyotish-datagol. Reports are handled confidentially.
